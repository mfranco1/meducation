# Currency notes

Names, schemes and editions that sources and older textbooks still use but that are retired. Read this before writing or reviewing, and use the current form. Mention the old name only as "formerly called" where it helps a learner; keep guideline titles as published.

When a lesson finds another retired term, add a row. When the current form here is itself superseded, change the row; don't keep both.

| Retired | Current | Since |
| --- | --- | --- |
| FDA pregnancy letter categories (A, B, C, D, X) | Narrative pregnancy and lactation labeling (PLLR); never test the letters | 2015 |
| Polycystic ovary syndrome (PCOS) | Polyendocrine metabolic ovarian syndrome (PMOS) | 2026 consensus |
| NAFLD, NASH | MASLD, MASH | 2023 multisociety nomenclature |
| Pituitary adenoma | Pituitary neuroendocrine tumor (PitNET) | WHO Classification of Tumours, 5th ed. |
| Pre-2021 CNS tumor names (IDH-mutant glioblastoma) | IDH-based WHO CNS5 names: glioblastoma is IDH-wildtype only; IDH-mutant grade 4 is astrocytoma | WHO CNS5, 2021 |
| Extranodal NK/T-cell lymphoma, nasal type | Extranodal NK/T-cell lymphoma | WHO-HAEM5, 2022 |

## Current editions

- Tumor classification: WHO Classification of Tumours, 5th edition.
- Staging: AJCC 8th edition, unless the site has a Version 9 chapter; check the site before writing a stage.
