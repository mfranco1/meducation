# Fetch access

Sites that refuse automated fetches, and the route that loads instead. Shared by write-quizzes and write-flashcards. When a fetch fails, grep this file for the failing host (`grep -i "<domain>" .agents/shared/fetch-access.md`), then for the issuing body. The source ledger records blocked documents; this file records blocked sites.

## Terms

- **UA curl**: `curl -sL` with a browser User-Agent.
- **Archive copy**: `save-source <URL> --from web.archive.org/web/<year>id_/<URL>` (`id_` returns the raw page or PDF). WebFetch refuses web.archive.org.
- **PMC copy**: the article in PubMed Central, read as the PubMed Central entry says.
- **WebFetch PDF**: when WebFetch returns a PDF as binary, save it and read it with `pdftotext -layout`.

First check `var/sources/manual/` for a copy the user downloaded (`ls var/sources/manual/`) and save it with `save-source <the document's own URL> --from var/sources/manual/<file>`.

For a site not listed: PMC copy, then archive copy, then a copy hosted by another society, agency or university repository; otherwise record the fact as abstract-only.

Use only the routes listed. After a site refuses a fetch, don't retry its own host with a browser User-Agent or other URL variants: the permission classifier reads that as getting around access control and then refuses the archive copy too. When the classifier denies a fetch, don't retry or rephrase it: record the document as `blocked` and name it in your summary so the user can download it into `var/sources/manual/`.

## Indexes

- **PubMed Central** (pmc.ncbi.nlm.nih.gov; browser check): UA curl on the article page, then Europe PMC full text (`https://www.ebi.ac.uk/europepmc/webservices/rest/<PMCID>/fullTextXML`), then NCBI efetch (`https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pmc&id=<PMCID digits>`), then WebFetch on the article page. Find the copy with `https://pmc.ncbi.nlm.nih.gov/search/?term=<DOI>`, or with `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pmc&retmode=json&term=<plain URL-encoded words>` (bracketed field tags fail; wait about 2 s between eutils calls or they return non-JSON). Articles outside the open-access subset come back without text: record them as abstract-only. Pre-2000 page scans have no text layer, but the UA-curl article page lists the scan images (`cdn.ncbi.nlm.nih.gov/pmc/blobs/...png`), which download and can be read as images; `save-source` can't store them.
- **PMC article page via WebFetch** (returns the browser verification page): Europe PMC `fullTextXML` through curl, then strip tags; `save-source <PMC URL> --from <fullTextXML URL>` stores it. The Europe PMC REST search with `format=json` can fail intermittently and returns a record without `pubYear` for some hits, so check keys before indexing. A university repository PDF (for example eprints.whiterose.ac.uk) that WebFetch saves can be read with `pdftotext` from the saved path. The ACR Appropriateness Criteria `acsearch.acr.org` page shows only "Coming Soon"; a hosted copy of the ACR PDF (widionline.xray.ufl.edu) reads with `pdftotext -layout`.
- **PubMed** (pubmed.ncbi.nlm.nih.gov; cookie wall), **BVS / LILACS** (search.bvsalud.org, pesquisa.bvsalud.org): Europe PMC REST search for the abstract and citation: `https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=EXT_ID:<PMID>%20AND%20SRC:MED&resultType=core`.
- **NCBI Bookshelf** (ncbi.nlm.nih.gov/books, GeneReviews; CAPTCHA): another agency's copy. Europe PMC search plus `fullTextXML` works for PMC articles; for StatPearls and other Bookshelf chapters (NBK IDs) the PMID search returns only the abstract (record it as summary-only), so for a textbook fact beyond the abstract use a journal article found through Europe PMC. Endotext chapters: UA curl of the chapter PDF from endotext.org (`https://endotext.org/wp-content/uploads/pdfs/<chapter-slug>.pdf`), then `pdftotext`.

## Archive copy works

These return 403 or HTML instead of the PDF; the archive copy loads: clinicalinfo.hiv.gov (NIH HIV guideline PDFs and OI chapter pages; the CMV chapter loads only from 2024 snapshots), BMJ specialty journals (lupus.bmj.com and other *.bmj.com article pages; for gut.bmj.com only the `/content/gutjnl/<vol>/<issue>/<page>.full.pdf` URL; not jnnp.bmj.com), DOH Epidemiology Bureau surveillance PDFs (pia.gov.ph), FNRI-DOST (fnri.dost.gov.ph: Pinggang Pinoy, dietary guidelines), National Academies Press (nap.nationalacademies.org: IOM reports), NIH ODS fact sheets (ods.od.nih.gov), Philippine Statistics Authority (psa.gov.ph), SAGE journal articles (journals.sagepub.com/doi/full/<DOI>, such as *Otolaryngol Head Neck Surg*; the archive copy comes back gzip-compressed, so decompress it before reading), SAGES guidelines (sages.org/publications/guidelines pages), *Respiratory Care* (rcjournal.com), SOGC (*J Obstet Gynaecol Can*, `jogc.com/article/<PII>/pdf`), The Menopause Society (menopause.org PDFs; or the *Menopause* article in PMC), UNICEF data (data.unicef.org: UN IGME reports).

## Drug labels

Cite the US prescribing information. DailyMed is sometimes unreachable; use the openFDA label API with curl:

- `https://api.fda.gov/drug/label.json?search=openfda.generic_name:<drug>&limit=1` with one unquoted word (quoted often returns "all shards failed"; search a combination product by its full name). Read `adverse_reactions` and `effective_time`.
- A generic name can return another product first (Jynarque for tolvaptan, Kadcyla for trastuzumab); some brands (Zyban) return nothing. Narrow with `+AND+indications_and_usage:<word>` or `openfda.brand_name:<brand>`, and by route with `+AND+openfda.route:INTRAVENOUS` (topical labels otherwise come first) or `ORAL` (tranexamic acid).
- OTC labels have no adverse-reaction section. Prescription-and-OTC drugs (loperamide): add `+AND+_exists_:adverse_reactions`. OTC-only (nicotine replacement): UK SmPC at `medicines.org.uk/emc/product/<id>/smpc`.
- Missing from openFDA (dimercaprol): `https://dailymed.nlm.nih.gov/dailymed/services/v2/spls.json?drug_name=<brand>`, then the SPL XML by setid.
- Withdrawn in the US (single-ingredient indacaterol): the EMA SmPC (see EMA), or the old label PDF on accessdata.fda.gov by UA curl.
