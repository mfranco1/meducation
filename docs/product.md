# Product behavior

The app supports one-question-at-a-time quizzes, flags, a stopwatch, immediate feedback and deferred exam feedback, result summaries, and metadata analytics. Learning Mode offers Fast Feedback: selecting an answer locks it and immediately reveals correctness and feedback. Every newly committed correct answer receives a brief, local green-circle burst; incorrect answers and answer keys under review do not. Correct Fast Feedback answers build an attempt-local streak in answer-commit order; an incorrect committed answer resets it and lets the learner earn streak celebrations again. A small non-blocking celebration appears at 3, 5, 10, 25, and 50 correct answers in a row. Streak progress survives leaving and resuming, but Exam Mode never exposes a live streak, correctness, or success animation before submission. Completing a non-empty test with every answer correct shows a distinct perfect-test celebration on the results screen in either mode; this uses exact correct and total counts, not the rounded percentage. Attempts are private to the browser via localStorage. Dashboard progress focuses on each subject's most recent completed score: it shows the equal-weighted average of those scores, their lowest value, and each subject's latest score. The lowest-score card names the subject with that score; ties use the subject whose latest score was completed most recently. When the latest and immediately previous completed scores are available, a subject card also shows a green upward triangle for an increase, a red downward triangle for a decrease, or a horizontal line in the latest-score text color when they are equal. A subject's test cards show completion count and latest score, with a separate lowest score when it differs. The stopwatch counts only while the learner is on an active quiz screen: leaving, reloading, or closing a test pauses it, and resuming continues from the saved elapsed time. A back arrow above the question opens one exit dialog where leaving saves progress, aborting discards it, and dismissing the dialog continues the test. Learners can leave an in-progress test without discarding it and later resume at the last viewed question; aborting a test discards that saved progress.
