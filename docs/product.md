# Product behavior

The app supports one-question-at-a-time quizzes, flags, a stopwatch, immediate feedback and deferred exam feedback, result summaries, and metadata analytics. Learning Mode offers Fast Feedback: selecting an answer locks it and immediately reveals correctness and feedback. In Exam Mode, selections remain editable and feedback stays hidden until the learner submits the test. Attempts are private to the browser via localStorage. Dashboard progress focuses on each subject's most recent completed score: it shows the equal-weighted average of those scores, their lowest value, and each subject's latest score. A subject's test cards show completion count and latest score, with a separate lowest score when it differs. The stopwatch counts only while the learner is on an active quiz screen: leaving, reloading, or closing a test pauses it, and resuming continues from the saved elapsed time. A back arrow above the question opens one exit dialog where leaving saves progress, aborting discards it, and dismissing the dialog continues the test. Learners can leave an in-progress test without discarding it and later resume at the last viewed question; aborting a test discards that saved progress.
