# Product behavior

The app supports one-question-at-a-time quizzes, flags, a stopwatch, immediate feedback and deferred exam feedback, result summaries, and metadata analytics. In Learn as you go mode, selecting an answer locks it and immediately reveals correctness and feedback. In Exam mode, selections remain editable and feedback stays hidden until the learner submits the test. Attempts are private to the browser via localStorage. The stopwatch counts only while the learner is on an active quiz screen: leaving, reloading, or closing a test pauses it, and resuming continues from the saved elapsed time. Learners can leave an in-progress test without discarding it and later resume at the last viewed question; aborting a test discards that saved progress.
