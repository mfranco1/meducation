# Public deployment acceptance after L6

Content-source update (2026-10-16): the [PostgreSQL-only retirement](../done/postgres-only-content-retirement-plan.md) removes repository JSON databases, runtime read fallbacks and file-authoring modes. PostgreSQL and authenticated HTTP CRUD are the current contract; earlier stage statements and machine evidence below remain historical. This does not close unrelated hosted identity, retention, device or deployment gates.

Created: 2026-10-15 (Asia/Manila). Status: pending; local candidate accepted, public launch blocked. This checklist records subsequent obligations only; it does not authorize provisioning or deployment.

Entry point: [deployment handoff](../../L6-deployment-handoff.md). Accepted inputs: [final L6 decision](../done/L6-final-decision-evidence.json), [candidate CI](../done/L6-step5-native-ci-evidence.json), [completed L6 plan](../done/L6-local-release-candidate-plan.md). Parent: [production preparation](local-first-production-preparation.md). Owners below are roles to assign before execution; nobody is assumed to have accepted an assignment.

- [ ] **Provider/database operator — host and PG17 selection.** Close with a dated review of current official provider documentation, chosen host/database region, role and endpoint support, explicit production bootstrap recipe, quotas, budget limits and alerts, and measured Philippine warm/cold latency. Provisional Neon/API-host/OIDC options are not commitments. Record actual TLS handshake/trust and least-privilege reader/session/editor/backup/migrator compatibility; runtime receives no owner credentials.
- [ ] **Provider/database operator — pooling and wake behavior.** Close with deployed direct/pool transaction/session compatibility, one API process and six-slot aggregate role budget, actual suspend/wake and stale-connection recovery, twenty-launch fixture characterization and request-driven freshness observations. Confirm no polling/keepalive defeats suspension. Local PostgreSQL restart tests cannot certify these properties.
- [ ] **Identity/security operator — real production identity.** Implement the provider adapter and hosted role bootstrap before enabling private public admin. Close with actual issuer/audience/claim validation, factor assurance/fresh-MFA and forced step-up, callback/PKCE/origin/CSRF handling, key/secret rotation, logout/revocation/recovery and synthetic-mode rejection. This requires implementation and provider acceptance; loopback fixture success or a credential swap cannot close it.
- [ ] **Release/domain operator — stable origin and progress transfer.** Close with a stable HTTPS domain and tested same-origin private API/callback routes, documented previous-origin paired progress export and new-origin preview/replace/restore, failure recovery and usable file workflows. Learner data remains browser-local; no backend progress or sync is authorized.
- [ ] **Recovery/database operator — retained independent recovery.** Preserve the user-deferred local-only retention decision until explicitly reopened. Close hosted admission with independently retained protected full backup, allocation fence and current journals, lineage/writer retirement policy, fresh auth epoch, off-device retention/RPO/RTO and a measured restore to a separate target. Never restore over the routine authority or run the offline rehearsal while its writers remain active. The [L4 tracker](L4-local-authoring-admin-access-plan.md) and [recovery runbook](../../L4-authoritative-recovery.md) remain authoritative; paired content parity alone cannot close this gate.
- [ ] **User/device acceptance owner — browsers and real devices.** Close the individual [browser acceptance](L0-browser-acceptance.md#l6-accepted-engine-refresh--2026-10-15) cases with device/OS/browser versions and retained observed results: user-deferred Firefox, actual iOS Safari/Android Chrome file workflows, actual screen-reader/keyboard interaction, persisted BFCache/freeze-return. Emulation, Playwright WebKit and synthetic lifecycle events cannot substitute. Do not retry the deferred Firefox installation without reopening that decision.
- [ ] **Release/security operator — deployed artifacts, routing and smoke.** Pin source commit, selected immutable export/schema and registry manifest digests; recheck active publication before a transfer and explicitly choose whether to recapture/retest a newer pair. Run ordered handoff checks for TLS/cookies/origin/proxy trust, cache and body/time limits, secret installation/rotation, admin exclusion/separation, startup/health/private denials, fresh learner revision/launch, progress restore, protected diagnosis and rollback/roll-forward. Keep public admin disabled until identity gates pass. Retain sanitized commands, outputs and cleanup evidence; never treat readiness during an outage as proof of DB connectivity.
- [ ] **Release operator — final public-launch decision.** Collect the preceding evidence, assigned owners and sign-off; refresh candidate checks if relevant inputs change. Decide whether to retain/download or regenerate the native/browser CI artifact payloads before their GitHub expiry on 2026-10-29. The frozen receipt contains metadata/digests only; local image IDs are not registry digests. Record a separate explicit public-launch authorization. No deployment is completed by checking local L6 requirements.

No gate above passes on the strength of planning alone. Preserve failures and reruns, use disposable resources for destructive/load/authoring drills, and avoid secrets/private drafts/personal progress in repository evidence.
