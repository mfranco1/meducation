# Design system

The dashboard's active-subject carousel is user-controlled, never auto-advances, and uses labelled previous/next controls with wraparound navigation. Show those controls only when its cards overflow the visible responsive layout; otherwise present the cards as a static row. Its subject card uses native button semantics and visible focus treatment; reduced-motion navigation jumps directly to the next card.

Meducation uses a light, warm autumn palette with `#b9511b` as its restrained primary accent, off-white surfaces, strong type hierarchy, soft borders, 14px radius cards, and visible native MUI focus states. Correctness always combines written feedback, an icon, and color. Immediate feedback uses a compact tinted status header followed by a neutral reading surface; long explanations should have a clear heading, generous line height, and a constrained readable measure rather than a fully tinted wall of text. The shared Markdown renderer presents canonical stems and rationales as semantic paragraphs, headings, nested lists, blockquotes, tables, code, and links; tables must scroll horizontally on narrow screens. The highlighted answer choices communicate which selection was correct or incorrect, so do not repeat answer summaries in feedback. Render optional high-yield pearls as separate callouts. A correct-answer choice receives a short, local green-circle burst, while centered celebration overlays remain reserved for streak and perfect-test events. Both effects are decorative, pointer-transparent, and non-blocking: they do not move focus, obscure controls, or shift layout. They honor `prefers-reduced-motion` by omitting moving circles while preserving written and static correctness signals. Visual formatting must not change canonical Markdown semantics.
